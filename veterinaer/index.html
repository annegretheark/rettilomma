Backup / Restore / Import

Kun systemadmin. Her kan du ta backup og importere behandlinger/varer.

Backup

Lokal backup lastes ned til PC. Supabase-backup lagres i privat Storage-bucket og kan også kjøres automatisk hver natt.

Restore

Importer behandlingspriser

Importer medisiner/varer til lager

Faktura veterinær
