1. Start med moduler

Rett i Lomma er modulbasert. Kunden skal bare få de modulene de faktisk trenger. En liten ENK kan starte enkelt, mens en håndverkerbedrift kan legge til biler, varer, lager og lønn når behovet kommer.

Solo / ENK

Timer, kunder og enkel faktura.

Håndverker

Timer, jobber, varer, biler, Min bil, lager og faktura.

Konsulent

Timer, prosjekter og faktura uten bil-lager.

Pro / Admin

Full pakke med lønn, lager, økonomi og backup.

2. Logg inn som administrator

Administrator logger inn for å åpne admin-konsollen. Admin-konsollen er hovedinngangen til oppsett, moduler, firma, ansatte, kunder, faktura, lager, lønn og backup.

Innlogging

Brukeren logger inn med e-post og passord. Vanlige brukere sendes til en enkel arbeidsflate.

Kommentar: Dette bildet hører til kapittelet over og viser hva administrator eller bruker faktisk skal gjøre.

Logg inn som admin

Administrator kan velge adminmodus ved innlogging. Dette åpner funksjoner som vanlige brukere ikke skal se.

Kommentar: Dette bildet hører til kapittelet over og viser hva administrator eller bruker faktisk skal gjøre.

Admin-konsoll

Admin-konsollen er navet for oppsett og vedlikehold. Herfra kan administrator gå videre til moduler, firma, ansatte, kunder, faktura, lager, lønn, backup og testpanel.

Kommentar: Dette bør vises tidlig i dokumentasjonen, fordi administrator først må forstå hvor hovedstyringen ligger.

Adminvalg

Adminvalg brukes for å skille mellom vanlig bruk og administrasjon. En administrator kan jobbe som vanlig bruker, eller åpne adminmodus når systemet skal settes opp eller vedlikeholdes.

Kommentar: Dette bildet forklarer rolleforskjellen mellom enkel daglig bruk og administrasjon.

10. Backup og sikkerhet

Backup skal være trygg uten å bli en daglig bekymring. Systemet kan settes opp med automatisk backup i skyen.

Automatisk backup i skyen: Backup kan kjøres automatisk etter fast oppsett, for eksempel hver natt. Kunden trenger ikke huske dette selv.
Manuell backup: Administrator kan ta ekstra backup før import, større endringer eller vedlikehold.
Hva sikres?
Data som kunder, timer, varer, lager, faktura og oppsett.
Hvorfor?
For å kunne gjenopprette etter feil, sletting eller uhell.
Hvem gjør det?
Automatisk jobb i skyen. Administrator kan i tillegg ta manuell backup.

11. Hva ser vanlig bruker?

Vanlig bruker skal ha en enkel arbeidsflate. De skal normalt se Timer, Jobber og Min bil. De skal ikke se lønn, faktura, ansatte, firma, backup eller adminfunksjoner.

Vanlig bruker ser:
Timer, Jobber og Min bil.
Vanlig bruker ser ikke:
Lønn, faktura, firma, ansatte, backup og adminfunksjoner.
Hvorfor?
Færre valg gjør systemet tryggere og enklere i daglig bruk.
