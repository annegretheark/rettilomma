Brukerdokumentasjon

Handverkerapp - strukturert veiledning for daglig bruk på mobil og PC. Dokumentasjonen beskriver hovedmodulene, vanlige arbeidsflyter, roller og anbefalt bruk.

For ansatte

Registrer timer, fravær, varer, utlegg og arbeid knyttet til kunde/prosjekt.

For admin

Administrer kunder, tilbud, faktura, varer, biler, ansatte, lønn og firmaoppsett.

For systemadmin

Administrer bedrifter, moduler, backup, restore og teknisk testpanel.

Kom i gang

  1. Åpne appen og logg inn med e-post og passord.
  2. Bruk toppmenyen på PC eller mobilmenyen på telefon for å velge modul.
  3. Velg kunde/prosjekt der dette kreves før du registrerer timer, varer, tilbud eller faktura.
  4. Lagre alltid endringer før du bytter skjerm.
  5. Ta backup før større endringer i firma, moduler, ansatte eller systemoppsett.
Tips: På mobil bør du arbeide én oppgave om gangen. Fullfør og lagre skjemaet før du går videre til neste skjerm.

Roller og tilgang

RolleHva rollen vanligvis gjør
AnsattRegistrerer timer, fravær, varer/utlegg og bruker egen bil-/lageroversikt.
AdminHåndterer kunder, prosjekter, tilbud, faktura, varer, biler, ansatte, lønn og firma.
SystemadminSetter opp bedrifter, moduler, backup/restore og tekniske tester.

Daglig arbeidsflyt

  1. Start dagen: Kontroller aktiv bil og at nødvendige varer finnes på bil/lager.
  2. Under arbeid: Registrer timer, varer, utlegg, kilometer og bilder fortløpende.
  3. Etter arbeid: Kontroller at riktig kunde og prosjekt er valgt før lagring.
  4. Admin: Følg opp tilbud, fakturagrunnlag, purringer, lager og lønn etter behov.

Timer

Registrer arbeidstid, varer, utlegg, kilometer og bilder på kunde/prosjekt.

Tilgang: Ansatt/Admin

Viktige felterTypisk bruk
Dato, kunde, prosjekt, start/slutt, timepris, bil, varer, utlegg, beskrivelse og bilde.Velg kunde og prosjekt, fyll inn tid og eventuelle varer/utlegg, legg til bilde ved behov, og trykk Lagre timer.

Jobber

Vis og oppdater registrerte jobber.

Tilgang: Ansatt/Admin

Viktige felterTypisk bruk
Jobbliste og oppdateringsknapp.Bruk Oppdater jobber for å hente siste oversikt.

Fravær / Flexi

Registrer fravær, ferie, sykdom eller flexitid og send til godkjenning.

Tilgang: Ansatt/Admin

Viktige felterTypisk bruk
Ansatt, type, datoer, timer per dag og kommentar.Fyll inn perioden, legg inn kommentar ved behov, og send til godkjenning.

Min bil / lager

Administrer bil, bil-lager og bestilling av varer til bil.

Tilgang: Ansatt/Admin

Viktige felterTypisk bruk
Bil, reg.nr, varer på bil, hvem som henter varene og bestilling til admin.Velg bil, kontroller varer, registrer behov og send bestilling.

Kunder

Opprett og vedlikehold kunder og prosjekter.

Tilgang: Admin

Viktige felterTypisk bruk
Kundenr, navn, adresse, e-post, telefon, timepris, kontaktperson og prosjektdetaljer.Bruk Ny kunde for nytt kundeforhold. Bruk Legg til prosjekt for arbeid knyttet til kunde.

Tilbud

Lag tilbud med tilbudslinjer, status, kunde og prosjekt.

Tilgang: Admin

Viktige felterTypisk bruk
Tilbudsnummer, dato, gyldig til, kunde, prosjekt, tekst, antall, pris og MVA.Fyll inn tilbudshode, legg til tilbudslinjer og lagre tilbudet.

Faktura

Lag faktura, purring, fakturakopi, kreditnota og økonomioversikt.

Tilgang: Admin

Viktige felterTypisk bruk
Kunde, fakturavalg, dato-intervall, MVA Excel og purring.Velg kunde eller faktura, kjør ønsket handling og kontroller resultat før utskrift/videre bruk.

Varer / lager

Opprett og importer varer, lagerstatus og priser.

Tilgang: Admin

Viktige felterTypisk bruk
Varenr, varenavn, innpris, påslag, utpris, lagerantall, minimum og MVA.Legg inn vare manuelt eller importer via Excel/CSV.

Biler / bil-lager

Opprett biler, tildel ansatt og administrer varer på bil.

Tilgang: Admin

Viktige felterTypisk bruk
Bilnavn, registreringsnummer, standard bil og bil-lager.Registrer bil og knytt den til riktig ansatt eller lagerflyt.

Lønn

Kjør lønn, lønnsslipper, kopier, skattetrekk og utbetalinger.

Tilgang: Admin

Viktige felterTypisk bruk
Måned, år, utbetalingsdato og ansattvalg.Velg periode og ansatt, kjør lønn og eksporter PDF/Excel ved behov.

Ansatte

Opprett ansatte, roller, standardbil, timepris og trekk.

Tilgang: Admin

Viktige felterTypisk bruk
Navn, e-post, mobil, rolle, standard bil, timepris og trekk.Fyll inn ansattinformasjon og lagre. Legg til trekk hvis aktuelt.

Firma

Rediger firmaopplysninger, logo, brevhode og betalingsinformasjon.

Tilgang: Admin

Viktige felterTypisk bruk
Firmanavn, adresse, e-post, kontonr, Vipps, org.nr, MVA nr, logo og brevhode.Oppdater opplysninger og lagre før dokumenter/fakturaer produseres.

Backup / Restore

Ta backup og gjenopprett fra backupfil.

Tilgang: Admin/Systemadmin

Viktige felterTypisk bruk
Backupfil og restore-funksjon.Ta backup før større endringer. Bruk restore kun når du er sikker på riktig fil.

Systemadministrasjon

Administrer bedrifter, moduler, kundelink og systeminnstillinger.

Tilgang: Systemadmin

Viktige felterTypisk bruk
Bedrift, moduler, invitasjon, midlertidig passord og kundelink.Opprett bedrift, velg moduler, lagre og send invitasjon ved behov.

Testpanel

Kjør tekniske tester og slett testdata.

Tilgang: Systemadmin

Viktige felterTypisk bruk
Helsetest, stresstest, faktura, MVA, rettigheter og testdata.Brukes kun ved testing/feilsøking, ikke i vanlig daglig drift.

Mobilbruk

  • Skjemaer vises best i én kolonne.
  • Tabeller kan vises som kort på små skjermer.
  • Bruk tydelige knapper og unngå å zoome unødvendig.
  • Kontroller alltid at lagring er gjennomført før du lukker nettleseren.

Backup og sikker bruk

  • Ta backup før større endringer.
  • Ikke bruk restore med mindre du vet at backupfilen er riktig.
  • Test nye rutiner i testpanelet eller med testdata før de brukes i produksjon.
  • Ikke del innlogging eller midlertidige passord med uvedkommende.
